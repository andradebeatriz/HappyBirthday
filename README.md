# 🎉 Happy Birthday App ۶ৎ

Um app Android feito com **Kotlin** e **Jetpack Compose** que gera um cartão de aniversário personalizado. A pessoa digita o próprio nome e recebe uma mensagem de "Happy Birthday" e uma assinatura fixa.

Projeto desenvolvido como estudo de **Jetpack Compose**, explorando gerenciamento de estado, animações e estilização de UI no Android.

## ୨ৎ Funcionalidades

- **Tela de entrada de nome**: a pessoa digita seu nome antes de ver a mensagem.
- **Mensagem personalizada**: o cartão de aniversário exibe o nome digitado dinamicamente.
- **UI customizada**: gradientes de cor, tipografia combinando fonte cursiva com serifada, e cards com cantos arredondados.

## ୨ৎ Tecnologias

- [Kotlin](https://kotlinlang.org/)
- [Jetpack Compose](https://developer.android.com/jetpack/compose)
- Material 3
- Compose Animation APIs (`AnimatedVisibility`, `rememberInfiniteTransition`)

## ୨ৎ Como rodar

1. Clone o repositório:
   ```bash
   git clone https://github.com/andradebeatriz/HappyBirthday.git
   ```
2. Abra o projeto no **Android Studio**.
3. Aguarde o Gradle sincronizar as dependências.
4. Rode o app em um emulador ou dispositivo físico (▶️).

## ୨ৎ Estrutura do projeto

```
app/src/main/java/com/example/happybirthday/
├── MainActivity.kt        # Telas e lógica principal do app (Compose)
└── ui/theme/               # Cores, tipografia e tema do Material 3
```
